# Legacy audit: probability and inference, weeks 29–60

This audit records the OLD curriculum exactly as stored in `data/lessons-01-35.json` and `data/lessons-36-70.json`. The legacy numbering is retained. For each of the five sessions per week, the table quotes a short theory fragment and worked example, then the actual exercise prompt and supplied answer. The final column states the gap against the requested graduate-core standard. Quotes are shortened only for scanability; the source JSON contains the full text.

## Coverage count

The legacy range contains 32 modules and 160 sessions. Every session has theory text, a worked example, one exercise prompt, one hint, and one answer/solution (160/160 for each field). This is real instructional material, not an empty shell. The quality gap is depth and assessment design: one exercise per session, no staged hint ladder, no multi-criterion rubric, no complete graduate proof sequence for several advanced results, and no explicit A/B gate blueprint/pass-critical/remediation contract. Weeks 29–52 are largely forecasting, optimization, ML, and workflow modules; probability/inference begins as an 8-week bridge at old W53.

The audit distinguishes an existing solved prompt from a proof: a correct short answer is credited as solution evidence, while the gap column records when the theory/prompt does not establish full hypotheses, a reusable derivation, or the requested graduate level. The authored canonical replacement reorganizes the material into W29–44 measure probability/processes and W45–60 inference.
