# Legacy audit: weeks 61–96

This is an evidence audit of the existing legacy curriculum shards. It records the old course as found before the canonical Math v2 rewrite; it does not change those files.

## Audit method and result

Inspected every week object from 61 through 96 in `data/lessons-36-70.json`, `data/lessons-71-86.json`, `data/lessons-87-93.json`, and `data/lessons-94-99.json`. All 36 weeks have exactly five sessions (180 session records). Every session has populated `theory`, `workedExample`, a four-item `agenda`, `deliverable`, and exactly one exercise with `prompt`, `hint`, and `answer`. The audit below records those fields with a short theory focus and a short answer-backed exercise trace for each session.

Assessment finding: the legacy records use one formative, answer-backed exercise per session and a deliverable; they contain no per-question pointwise rubric or standalone assessment object. Week 65 session 4 is the sole session explicitly titled as an exam/core assessment. The canonical W72 and W84 gates below are new A/B assessments with different proof arguments; their existence should not be attributed to the old course.

## Coverage judgment

- **W61–70:** mixed depth rather than uniformly graduate. W61–64 mainly use familiar parametric likelihood/inference calculations; W65 is the explicit core exam but has a narrow task mix; W66–68 mostly exercise introductory uniform-bound or nonparametric calculations; W69–70 provide the strongest optimization derivations, still with many short numeric prompts.
- **W71–72:** useful online evaluation and latent-state/filtering applications, with specific exercises. The old W72 is a forecasting/filtering workflow week rather than an optimization gate; it does not supply the later 5-day canonical gate assessment.
- **W73–88:** predominantly research reproduction, protocol, implementation and benchmark design/execution. These weeks do contain quantitative reasoning and answered exercises, but their five-session record is not a sustained graduate-theory sequence.
- **W89–96:** adaptation, calibration, ablation, robustness, paired-dependence and economic-interpretation studies followed by synthesis/manuscript work. W89 has an explicit dynamic-tracking calculation; W93 introduces dependent comparisons and block resampling. The older W84 is preregistration/holdout discipline, not the canonical dependence gate.
- **Canonical replacement plan:** weeks 61–96 are rewritten as self-contained bilingual mathematical instruction with theorem hypotheses/proofs or stated black boxes, original worked examples and failure cases, five answer-backed exercises with pointwise rubrics, and five 240-minute agendas. W72 assesses primal/dual reasoning, convergence and numerical failure in each alternative form; W84 assesses distinct dependence arguments. W91 dynamic regret is explicitly specialization/elective depth. The later state-space capstone remains in W97–105.
